# Machine learning

Training and evaluation code that runs on Kaggle and Modal GPUs, never on the serving path:

- case and dial segmentation (StarDist), compared with baselines (Phase 2);
- the image embedder that identifies the worn watch (Phase 2);
- lighting harmonisation (Phase 3);
- the Studio LoRA (Phase 4);
- synthetic training data (Phase 1).

Weights and run outputs never enter the repository; model cards go in [docs/cards](../docs/).
